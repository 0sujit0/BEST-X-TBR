# Supervisor flow — agreed 2026-10-12 (D-013)

1. Caseload dashboard: assigned therapists and clients
2. Flagged sessions: sessions with alerts, most alerts first
3. Open session: confirmed summary, timeline, trends
4. Summary confirmed?
   - No: "Summary pending" shown; supervisor can remind the therapist
   - Yes: optional actions, any order:
     - Compare sessions (side-by-side view)
     - Approve documentation where permitted (scope open — Q-19)
     - Add review note or follow-up task → appears in therapist's pending tasks
5. Mark session reviewed (logged for audit)
