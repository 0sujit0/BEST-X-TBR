- **Date:** 2026-10-09

## Decision
PRD v3.0 is a clean scope document:
1. AI summary is generated by an external AI service via API (not built by TBR); the platform sends session data, receives the draft, and displays it for the therapist to review, edit and confirm.
2. Parents are not mentioned, except that the parent signs consent with clinic staff, who record it in the platform.
3. Data format for wearable / sensor readings is defined.
4. Alert signals are written to a notification queue / table that the UI consumes.
5. Removed entirely: all Phase 2 items, the "Future" term and its items, AI Strategy section, Non-Functional Requirements section, BEST Finance & Billing user, all PROPOSED tags, Items Pending BEST Input.
6. Licensing: no payment verification; a licensing table with maintenance capability.
7. New: DEV, UAT, PRODUCTION environments with a three-branch deployment strategy.
