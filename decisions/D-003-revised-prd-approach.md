# D-003: Revised PRD format — proposals marked, clean doc with change log

- **Date:** 2026-10-09
- **Phase:** Definition
- **Status:** Superseded by D-010
- **Owner:** Sujit
- **Supersedes:** —

## Decision
- Where BEST has not answered an open question, the revised PRD writes in TBR's recommendation and marks it **Proposed**.
- Deliver as a clean document plus a change-log appendix (change, reason, original section).

## Rationale
BEST reads a complete product spec rather than a list of gaps; every deviation from their original is visible and traceable.

## Options Rejected
| Option | Why rejected |
|---|---|
| Leave gaps as open questions in the PRD | Reads as incomplete; slows sign-off |
| Tracked changes | Hard to read across a 20-section document |

## Revisit Trigger
BEST asks for tracked changes.
